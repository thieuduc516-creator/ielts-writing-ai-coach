# IELTS Writing AI Coach

A static web demo for an IELTS Writing practice chatbot.

## Features

- Direct IELTS Writing task display
- Essay editor
- Estimated band demo
- Sentence-by-sentence correction
- Band vocabulary suggestions
- Exportable feedback report

## Deployment

This repository is ready for GitHub Pages.

Go to:

Settings → Pages → Deploy from a branch → main → /root → Save

Then open the GitHub Pages URL.
